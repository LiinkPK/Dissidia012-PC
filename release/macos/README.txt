Dissidia 012 Final Fantasy HD Remastered (macOS, Intel and Apple Silicon)
1. Put your own ISO (ULES01505 or ULUS10566) in game/
2. In Terminal, in this folder:  ./run.sh   (the first run sets the game up from the ISO)
HD textures: data/textures/ULES01505.
If macOS says the app cannot be opened: System Settings > Privacy & Security > Open Anyway, or run
  xattr -dr com.apple.quarantine .
Needs macOS 12 or newer. Graphics run through MoltenVK (Metal).
