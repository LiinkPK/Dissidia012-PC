Dissidia 012 [duodecim] Final Fantasy - HD Remastered (PC)

1. Double-click "requirements.bat" once. It installs what the game needs (Vulkan, Visual C++ runtime).
2. Put your own copy of the game (.iso: European ULES01505 or North American v1.00 ULUS10566) in the "game" folder
   and run "requirements.bat" again, or start the game and drop the ISO onto its window.
   The game files are NOT included and never will be.
3. Start "d012_native.exe" (it shows as Dissidia 012 Final Fantasy HD Remastered in Task Manager).

Saves from PPSSPP: in the game open the menu (Esc) > System > Saves and import your PPSSPP SAVEDATA folder
(PSP\SAVEDATA, the folder named ULES01505...). Your old saves are backed up first.

60 fps: menu > Video > Frame rate. The HD texture pack is in data\textures\ULES01505.

Third-party software: FFmpeg (LGPL, see FFmpeg-LICENSE.txt and FFmpeg-SOURCE.txt), SDL3, Dear ImGui and others
bundled by PortableKit keep their own licences.
